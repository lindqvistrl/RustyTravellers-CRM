# Rusty Travellers CRM

Ett kontaktregister för återförsäljare som jag bygger till mitt eget företag, Rusty Travellers. Jag använder det för att hålla ordning på vilka butiker jag har kontaktat, vad de svarade och när jag ska höra av mig igen.

Projektet är under utveckling. Jag bygger det vid sidan av studierna för att öva på HTML, CSS och JavaScript i något jag själv har nytta av.

## Klart

- HTML-struktur för kontaktlista och formulär

## På gång

1. Styling av knappar, tabellrubriker och formulär
2. Lägga till, visa, redigera och ta bort kontakter
3. Exportera till CSV
4. Importera från CSV
5. Mejlmallar
6. Skicka mejl direkt från systemet
7. Hämta företagsuppgifter från Bolagsverkets API med organisationsnummer

## Byggs med

HTML, CSS och JavaScript utan ramverk. Data ska sparas lokalt i webbläsaren med localStorage.
